Добро пожаловать в TurboBird
TurboBird — это инструмент администрирования баз данных Firebird. При первом запуске дерево слева пустое — это нормально. TurboBird может работать с базами данных только после того, как зарегистрированы две вещи. Порядок важен:

Приступить к работе
Все инструменты доступны
Первый запуск? Дерево слева пустое — начните с Регистрация сервера. Только после добавления сервера можно создать новую базу данных на этом сервере или зарегистрировать существующую.
1Зарегистрировать сервер
Сервер — это экземпляр Firebird, локальный или удалённый. Без хотя бы одного зарегистрированного сервера нельзя управлять ни одной базой данных.
SRV
Регистрация сервера
Добавить новый сервер или изменить существующий
LIB
Выбрать клиент FB
Сменить клиентскую библиотеку
INV
Инвентарь серверов
Текстовый обзор всех серверов
2Создать, зарегистрировать или восстановить базу данных
База данных — это файл .fdb на сервере. Требование: зарегистрированный сервер.
NEW
Создать базу
Создать новую пустую базу Firebird
REG
Зарегистрировать базу
Подключить существующий файл .fdb
RST
Восстановить базу
Восстановить из резервной копии .fbk
BAK
Резервная копия базы
Создать файл резервной копии (выбрать БД)
