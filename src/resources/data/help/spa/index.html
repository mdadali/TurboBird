Bienvenido a TurboBird
TurboBird es una herramienta de administración para bases de datos Firebird. En el primer inicio, el árbol a la izquierda está vacío — esto es normal. TurboBird solo puede trabajar con bases de datos una vez que dos cosas estén registradas. El orden es importante:

Todas las herramientas disponibles
¿Primer inicio? El árbol a la izquierda está vacío — comience con Registrar Servidor. Solo después de agregar un servidor podrá crear una nueva base de datos en ese servidor o registrar una base existente.
1Registrar un servidor
Un servidor es la instancia de Firebird — local o remota. Sin al menos un servidor registrado, no se puede administrar ninguna base de datos.
SRV
Registrar Servidor
Agregar un nuevo servidor o editar uno existente
LIB
Seleccionar Cliente FB
Cambiar la biblioteca cliente
INV
Inventario de Servidores
Vista general en texto de todos los servidores
2Crear, registrar o restaurar una base de datos
Una base de datos es un archivo .fdb en un servidor. Requisito: un servidor registrado.
NEW
Crear Base de Datos
Crear una nueva base Firebird vacía
REG
Registrar Base de Datos
Vincular un archivo .fdb existente
RST
Restaurar Base de Datos
Restaurar desde respaldo .fbk
BAK
Respaldar Base de Datos
Crear archivo de respaldo (seleccionar BD)
3Trabajando con datos
Doble clic en un objeto para abrirlo directamente, clic derecho para mostrar el menú contextual.
