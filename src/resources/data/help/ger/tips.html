Verbindungen als Favoriten speichern

Speichern Sie häufig verwendete Verbindungen als Favoriten. Klicken Sie auf eine Datenbank in Ihrer Liste der zuletzt verwendeten Datenbanken, um schnell eine Verbindung herzustellen.

Testen von lang laufenden Abfragen

Wenn Sie testen möchten, wie TurboBird das Abbrechen oder Beenden aktiver Anweisungen handhabt, können Sie eine umfangreiche Abfrage ausführen, die Millionen von Zeilen erzeugt:

SELECT A.RDB$FIELD_NAME, B.RDB$FIELD_NAME
FROM RDB$FIELDS A
CROSS JOIN RDB$FIELDS B
CROSS JOIN RDB$FIELDS C;

Dies kann je nach Größe von RDB$FIELDS mehrere Millionen Zeilen erzeugen. Verwenden Sie dies, um die Schaltfläche Cancel oder die Überwachung über MON$STATEMENTS zu testen.

MON$STATE in MON$STATEMENTS verstehen

Die Überwachungstabelle MON$STATEMENTS zeigt den Status jeder aktiven SQL-Anweisung an. Das Feld MON$STATE kann die folgenden Werte annehmen:

ValueMeaning
0Leerlauf / abgeschlossen
1Aktiv (wird ausgeführt)
2Abrufen (Cursor ist geöffnet, Zeilen werden abgerufen)
3Kompilieren / Vorbereiten der Anweisung

Bei lang laufenden Abfragen wird in der Regel 1 oder 2 angezeigt. In Firebird gibt es keinen Status -1; einige ältere Tools verwendeten diesen für "unbekannt".
