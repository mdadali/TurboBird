Welcome to TurboBird
TurboBird is an administration tool for Firebird databases. On first start, the tree on the left is empty — this is normal. TurboBird can only work with databases once two things are registered. The order matters:

All tools available
First start? The tree on the left is empty — begin with Register Server. Only after a server has been added can you create a new database on that server or register an existing one.
1Register a server
A server is the Firebird instance — either local or remote. Without at least one registered server, no database can be managed.
SRV
Register Server
Add a new server or edit an existing one
LIB
Select FB Client
Change the client library
2Create, register, or restore a database
A database is a .fdb file on a server. Requirement: a registered server.
NEW
Create Database
Create a new empty Firebird database
REG
Register Database
Bind an existing .fdb file
RST
Restore Database
Restore from a .fbk backup
BAK
Backup Database
Create a backup file (select DB)
3Working with data
Double-click an object to open it directly, right-click to show the context menu.
