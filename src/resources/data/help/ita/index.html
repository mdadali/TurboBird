Benvenuto in TurboBird
TurboBird è uno strumento di amministrazione per database Firebird. Al primo avvio, l'albero a sinistra è vuoto — questo è normale. TurboBird può lavorare con i database solo dopo che due cose sono state registrate. L'ordine è importante:

Tutti gli strumenti disponibili
Primo avvio? L'albero a sinistra è vuoto — iniziare con Registra Server. Solo dopo aver aggiunto un server si potrà creare un nuovo database su quel server o registrare un database esistente.
1Registrare un server
Un server è l'istanza di Firebird — locale o remota. Senza almeno un server registrato, nessun database può essere amministrato.
SRV
Registra Server
Aggiungi un nuovo server o modificane uno esistente
LIB
Seleziona Client FB
Cambia la libreria client
INV
Inventario Server
Panoramica testuale di tutti i server
2Creare, registrare o ripristinare un database
Un database è un file .fdb su un server. Requisito: un server registrato.
NEW
Crea Database
Crea un nuovo database Firebird vuoto
REG
Registra Database
Collega un file .fdb esistente
RST
Ripristina Database
Ripristina da un backup .fbk
BAK
Backup del Database
Crea un file di backup (seleziona DB)
3Lavorare con i dati
Doppio clic su un oggetto per aprirlo direttamente, clic destro per mostrare il menu contestuale.
Strumenti per i dati
EDT

Visualizza e modifica tabelle e file CSV

Recupero dati da DB danneggiati

SCR
Motore di Script
