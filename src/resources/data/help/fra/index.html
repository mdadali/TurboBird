Bienvenue dans TurboBird
TurboBird est un outil d'administration pour les bases de données Firebird. Au premier démarrage, l'arborescence à gauche est vide — c'est normal. TurboBird ne peut travailler avec des bases de données qu'une fois deux éléments enregistrés. L'ordre est important :

Tous les outils disponibles
Premier démarrage ? L'arborescence à gauche est vide — commencez par Enregistrer un serveur. Ce n'est qu'après avoir ajouté un serveur que vous pourrez créer une nouvelle base de données sur ce serveur ou enregistrer une base existante.
1Enregistrer un serveur
Un serveur est l'instance Firebird — locale ou distante. Sans au moins un serveur enregistré, aucune base de données ne peut être gérée.

2Créer, enregistrer ou restaurer une base de données
Une base de données est un fichier .fdb sur un serveur. Prérequis : un serveur enregistré.
