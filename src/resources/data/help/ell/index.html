Καλώς ήρθατε στο TurboBird
Το TurboBird είναι ένα εργαλείο διαχείρισης για βάσεις δεδομένων Firebird. Στην πρώτη εκκίνηση, το δέντρο στα αριστερά είναι κενό — αυτό είναι φυσιολογικό. Το TurboBird μπορεί να εργαστεί με βάσεις δεδομένων μόνο αφού καταχωριστούν δύο πράγματα. Η σειρά είναι σημαντική:
1
Καταχώριση διακομιστή
Πού εκτελείται το Firebird;
 →
2
Προσθήκη βάσης δεδομένων
Νέα, υπάρχουσα ή αντίγραφο ασφαλείας
 →
3
Έναρξη εργασίας
Όλα τα εργαλεία διαθέσιμα
Πρώτη εκκίνηση; Το δέντρο στα αριστερά είναι κενό — ξεκινήστε με Καταχώριση Διακομιστή. Μόνο αφού προσθέσετε έναν διακομιστή, θα μπορείτε να δημιουργήσετε μια νέα βάση δεδομένων σε αυτόν ή να καταχωρίσετε μια υπάρχουσα.
1Καταχώριση διακομιστή
Ένας διακομιστής είναι η εγκατάσταση του Firebird — τοπική ή απομακρυσμένη. Χωρίς τουλάχιστον έναν καταχωρισμένο διακομιστή, καμία βάση δεδομένων δεν μπορεί να διαχειριστεί.

2Δημιουργία, καταχώριση ή επαναφορά βάσης δεδομένων
Μια βάση δεδομένων είναι ένα αρχείο .fdb σε έναν διακομιστή. Απαίτηση: καταχωρισμένος διακομιστής.
