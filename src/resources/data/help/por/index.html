Bem-vindo ao TurboBird
O TurboBird é uma ferramenta de administração para bancos de dados Firebird. Na primeira execução, a árvore à esquerda está vazia — isso é normal. O TurboBird só pode trabalhar com bancos de dados depois que duas coisas estiverem registradas. A ordem é importante:

Todas as ferramentas disponíveis
Primeira execução? A árvore à esquerda está vazia — comece com Registrar Servidor. Somente após adicionar um servidor você poderá criar um novo banco de dados nesse servidor ou registrar um banco existente.
1Registrar um servidor
Um servidor é a instância do Firebird — local ou remota. Sem pelo menos um servidor registrado, nenhum banco de dados pode ser gerenciado.
SRV
Registrar Servidor
Adicionar um novo servidor ou editar um existente
LIB
Selecionar Cliente FB
Alterar a biblioteca cliente
INV
Inventário de Servidores
Visão geral em texto de todos os servidores
2Criar, registrar ou restaurar um banco de dados
Um banco de dados é um arquivo .fdb em um servidor. Requisito: um servidor registrado.
NEW
Criar Banco de Dados
Criar um novo banco Firebird vazio
REG
Registrar Banco de Dados
Vincular um arquivo .fdb existente
RST
Restaurar Banco de Dados
Restaurar a partir de backup .fbk
BAK
Fazer Backup do Banco
Criar arquivo de backup (selecionar BD)
3Trabalhando com dados
Duplo clique em um objeto para abri-lo diretamente, clique com o botão direito para mostrar o menu de contexto.
