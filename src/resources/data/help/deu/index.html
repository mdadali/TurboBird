Willkommen bei TurboBird
TurboBird ist ein Verwaltungswerkzeug für Firebird-Datenbanken. Beim ersten Start ist der Baum links noch leer — das ist normal. TurboBird kann erst mit Datenbanken arbeiten, wenn zwei Dinge registriert sind. Die Reihenfolge ist wichtig:

Alle Werkzeuge verfügbar
Erster Start? Der Baum links ist leer — beginnen Sie mit Server registrieren. Erst wenn ein Server eingetragen ist, können Sie unter diesem Server eine Datenbank anlegen oder eine bestehende registrieren.
1Server registrieren
Ein Server ist die Firebird-Instanz — lokal oder entfernt. Ohne mindestens einen registrierten Server können keine Datenbanken verwaltet werden.
